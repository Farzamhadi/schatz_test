How to Host on GitHub Pages (2-Phone Setup)

                

                
            


            

                

                    ✓ Works Right Now in Preview!
                    In this preview window, cloud database sync is already connected and live. You can test dropping and picking up notes immediately! Follow the steps below when you are ready to publish this `index.html` file to your own GitHub account.
                


                

                    
Step 1: Save This File as index.html

                    
Copy the complete code from the editor into a file named index.html on your computer. Because everything (HTML, Tailwind CSS, and JavaScript) is packed into one self-contained file, you only need this single file.

                


                

                    
Step 2: Create a Free Firebase Database (For Cross-Phone Sync)

                    
So Phone A can save a note and Phone B can detect it at those coordinates, both phones need a shared cloud database:

                    
    
                        
  1. Go to console.firebase.google.com and click Create a project.
    2. 
                        
  2. In the left sidebar, click Build → Authentication → Get Started and enable Anonymous sign-in.
    3. 
                        
  3. Click Build → Firestore Database → Create Database and start in Test mode.
    4. 
                        
  4. Go to Project Settings (gear icon) → scroll down to Your apps → click the Web </> icon to get your firebaseConfig object.
    5. 
                        
  5. Paste your config into the https://schatz-4190d-default-rtdb.europe-west1.firebasedatabase.app/ variable inside index.html (around line 335).
    6. 
                    

                


                

                    
Step 3: Upload to GitHub & Enable GitHub Pages (HTTPS Required)

                    
Mobile browsers (iOS Safari & Android Chrome) require HTTPS to allow navigator.geolocation GPS access. GitHub Pages gives you HTTPS for free:

                    
    
                        
  1. Create a new public repository on GitHub.com (e.g., geodrop-app).
    2. 
                        
  2. Click Add file → Upload files and drag your index.html file in, then click Commit changes.
    3. 
                        
  3. Go to your repository's Settings → Pages (on the left menu).
    4. 
                        
  4. Under Branch, select main and click Save.
    5. 
                        
  5. Wait 60 seconds, then open https://your-username.github.io/geodrop-app/ on both phones!
    6.
